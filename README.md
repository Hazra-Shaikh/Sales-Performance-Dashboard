# 📊 Sales Performance Dashboard | Excel

An interactive sales analytics dashboard built using Microsoft Excel to monitor key performance indicators, explore revenue trends, and analyze sales performance across regions, product categories, customer types, and sales channels.

## 📌 Project Overview

The Sales Performance Dashboard transforms sales data into an interactive visual report, helping users explore business performance and identify key revenue contributors.

## 🔍 Dashboard Features

- **Monthly Revenue Analysis:** Track revenue trends from January to December.
- **Regional Performance:** Compare revenue across Central, East, North, South, and West.
- **Product Category Analysis:** Evaluate revenue across seven product categories.
- **Sales Channel Analysis:** Compare Corporate Sales, Marketplace, Online, and Retail Store performance.
- **Top 5 Products:** Identify the products generating the highest revenue.
- **Interactive Slicers:** Filter the dashboard by region, customer type, and product category.
